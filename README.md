## 📖 What It Does

AI OCR Studio converts scanned PDFs and images into searchable, editable text using on-device AI — entirely offline. No account required, no upload, no waiting on external servers.

---

## ✨ Features

- 📵 **Offline OCR** — all processing runs locally; nothing is sent to the cloud
- 📄 **PDF support** — extract text from multi-page scanned PDFs
- 🖼️ **Image support** — JPG, PNG, TIFF, and other common formats
- 🖥️ **Desktop UI** — Windows GUI for drag-and-drop conversion
- ⚡ **CLI** — scriptable command-line interface for batch workflows
- 🆓 **No subscription** — free to use, no account required
